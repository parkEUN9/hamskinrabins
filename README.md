아이스크림을 스쿱으로 뜨면 햄쮜가 나오는 뽑기 게임. 초등학교 저학년 여자아이 기준으로 만들었습니다.

## 이 폴더의 파일

| 파일 | 설명 |
|---|---|
| `index.html` | **게임 본체.** 이것 하나로 돌아갑니다(외부 파일 없음). 더블클릭하면 바로 열립니다. |
| `manifest.webmanifest` | 홈 화면에 설치할 때 쓰는 앱 정보 (이름·아이콘·전체화면) |
| `sw.js` | 서비스워커 — 인터넷 없이도 열리게 캐시합니다 |
| `icon-192.png` / `icon-512.png` | 홈 화면 아이콘 |
| `icon-512-maskable.png` | 안드로이드 원형·각진 아이콘용 |

**이 6개는 항상 같은 폴더에 함께 두세요.** 게임 파일이 곧 배포 파일이라 따로 복사할 것이 없습니다.

## 웹에 올리기 / 앱으로 만들기

1. 깃허브에 **햄스킨 전용 저장소**를 새로 만들고 (예: `hamskin`) 이 폴더의 파일을 전부 올립니다.
   - ⚠️ 마이 라이프 매니저와 **같은 저장소에 올리면 안 됩니다.** `manifest.webmanifest`·`sw.js`·`icon-*.png`
     파일명이 서로 같아서 덮어쓰고, 서비스워커 범위도 겹칩니다.
2. Settings → Pages → Deploy from a branch → main / (root) → 주소가 나옵니다.
3. 그 주소를 https://www.pwabuilder.com 에 넣으면 APK 를 뽑을 수 있습니다.
   (자세한 절차는 상위 폴더의 `APK-만들기-안내.md` 와 같습니다)

## 고친 뒤 다시 올릴 때

- **게임 내용만 고쳤다면** — `index.html` 만 올리면 됩니다. 화면은 네트워크 우선이라 새로고침 한 번에 반영됩니다.
- **아이콘이나 앱 이름을 바꿨다면** — `sw.js` 의 `hamskin-v1` 숫자를 올려서 함께 올려야 반영됩니다.
- 헷갈리면 그냥 매번 숫자를 올리세요. 손해 없습니다.
- 깃허브 페이지는 10분쯤 캐시가 붙으므로 올린 직후엔 옛 화면이 나올 수 있습니다.

## 데이터

아이가 모은 햄쮜는 폰(브라우저) 안에만 저장됩니다. 앱을 지우면 사라지니,
게임 안 **⚙️설정 → 저장 코드**를 복사해서 어딘가에 붙여두면 나중에 그대로 되살릴 수 있습니다.
